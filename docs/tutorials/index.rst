Tutorials
=========

Follow a workflow from prepared data to predictions and metrics. Each guide
focuses on the decisions specific to one modeling path and links to runnable
examples where available.

* :doc:`tile-level` covers patch-level classification.
* :doc:`slide-level` covers slide-level classification, regression, and survival.
* :doc:`detection` covers point-based cell prediction.
* :doc:`segmentation` covers dense pixel prediction.
